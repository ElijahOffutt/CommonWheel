# Marketing Website
The marketing website for Common Wheel is a central consumption and proliferation hub for the Common Wheel Project and Brand. The goal for the marketing site is to disseminate and provate a central hub for all Common Wheel associated copy, details and general information. 

The marketing site is built using the following 
- Angular as the front end framework
- Angular Material as the visual component library
- USWDS as the styling and UI library which adheres to the US standard for developing visual applications

The main site has dynamic elements including but not limited too
- Blog via WordPress CMS in Headless Mode
- Store via "Coming Soon"
- Investor and Investment live data analytics
- Portal access for Common Wheel Services
