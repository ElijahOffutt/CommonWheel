

# Client applications


### Naming convention
Client aplpications have a naming convention that follows this format 

```[purpose]-[implementation]-[type]```

for example marketing-web-mobile is the mobile version of the marketing site on the web. Web is not exclusive as most clients will be web based, but web in this context is foundational as a type of "vanilla" and or standard implementation.
